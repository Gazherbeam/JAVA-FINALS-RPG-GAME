PIXELKILN UI PACK - FREE SAMPLE
================================
45 sprites from the Oakheart (fantasy RPG) theme, at 1x and 2x,
plus a complete, working Godot 4 Theme for that theme and Unity
import settings beside every PNG.
(v1.4 - the sample grew from 33 to 39 sprites: it now
carries the release's headline, which is that the pack can build a
settings screen at all. Five of the six new files are the new dropdown
control - header in normal / hover / open, the popup list body and a
selected row - and the sixth is the new tab hover state. The four
scrollbar arrows in the Godot theme are also corrected: every one of
them pointed the wrong way from v1.0 to v1.3. See the full pack's
CHANGELOG.)
(v1.6 - the sample grows from 39 to 45 sprites: a slider
track with its new filled part and thumb, and the new number-spinner
button with its up and down arrows. The Godot theme in this sample now
themes every part of a slider, scrollbar and SpinBox. See the full
pack's CHANGELOG.)

UNITY
-----
Each .png has a .meta beside it: Sprite (2D and UI), Filter Mode
Point, no compression, and the 9-slice border already set on the
sprites that stretch. Keep them together when you copy the folder in.
The GUIDs in this sample are deliberately different from the paid
pack's, so you can install both into one project without a clash.
These files have never been opened in Unity - there is none on the
build machine - so what is checked is every value inside them, not
how they render.

GODOT 4
-------
godot_project/ opens and runs as-is. Copy pixelkiln_ui/ into the
root of your own project and assign
pixelkiln_ui/oakheart/theme.tres to your root Control - that is
the whole integration. Keep the folder name; the res:// paths
inside theme.tres are relative to it.

This sample ships the Oakheart theme only. The full pack has the
same treatment for Voidrunner and Bramble.
